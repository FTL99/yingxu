# 媒体 API 与使用说明

日期：2026-10-03。已封装接口并完成模拟协议测试，尚未使用真实账号生成或验证质量。

## 从哪里开始

1. 打开工作台 http://127.0.0.1:8811/ 的「运行设置」。填写火山方舟 API Key、阿里云百炼北京地域 API Key，然后点「保存媒体 API 配置」。万相和 CosyVoice 共用百炼 Key；业务空间 ID 可按账号需要填写。Key 留空保留已有值，勾选清除才删除。显示已保存只表示填写完成，不证明余额、权限或连接正常。
2. 到「分镜与素材」选择生成类型，填描述或配音文本。万相必须先选择本项目的一张首帧图片；可以先用 Seedream 生图或导入已有图片。聊天中的场景文字不会自动成为结构化镜头记录，描述可以直接粘贴。
3. 点「估算费用」，核对参数和预留金额，再点「确认生成」。保存 Key 和估算费用不调用供应商，确认生成才发送文本、所选参考图片并可能收费。
4. 生成完成后，图片、视频或配音进入本项目素材库。人工检查质量，在任务卡上按供应商账单填写实际金额和依据。预算预留不是供应商收费硬上限；不采用的成功生成也可能收费。

本项目先试 S6 甲板群战和 S8 舰队/跃迁等高风险镜头，核对真实成本、耗时和可用率，再决定批量制作。接口接入没有自动生成这两个镜头，也没有代用户放行阶段。

## 供应商与当前能力

| 类型 | 接入渠道 / 模型 | 当前适配能力 | 费用估算 |
|---|---|---|---|
| 生图 | 火山方舟官方 / `doubao-seedream-5-0-flash-260915` | 单张 PNG，0–10 张参考图，按项目画幅输出；不提供 seed、负面提示词、LoRA 或批量组图 | 0.12 元/张 |
| 图生视频 | 百炼北京官方 / `wan2.6-i2v-flash` | 单首帧，720P/1080P，时长参数，seed、负面提示词，可选声音；默认 720P 无声 | 无声 0.15/0.25 元每秒；有声 0.30/0.50 元每秒 |
| 配音 | 百炼北京官方 / 默认 `cosyvoice-v3-plus` | 文字生成 24kHz WAV，默认系统音色 `longanyang`，可设置已有兼容音色 ID | 3 Plus 为 2 元/万字符，3 Flash 为 1 元/万字符 |
| 配音可选 | 百炼北京官方 / `cosyvoice-v3.5-plus` 或 `cosyvoice-v3.5-flash` | 须填写该模型支持的设计/克隆音色 ID；没有系统音色，未实现创建音色接口 | 1.5 / 0.8 元每万字符 |
| 视频 | Seedance 中转站 / 用户填写模型名 | 720P、4–15 秒，文字或单首帧；OpenRouter 可选联合声音，生成前查目录支持；方舟兼容仅无声 | 有声/无声分别填写预算参考价；OpenRouter 按模型 SKU 以美元计费，实际费用单独记录 |

费用是本地估算，字符计数、账号优惠、实际用量、模型权限及最终账单以供应商为准。来源：[百炼定价](https://help.aliyun.com/zh/model-studio/model-pricing)、[火山方舟定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)。CosyVoice 3.5 音色限制见 [语音合成指南](https://help.aliyun.com/zh/model-studio/realtime-tts-user-guide)。

## Seedance 中转站怎么填

展开「运行设置」中的 Seedance，填写该站 API 根地址、专用 Key、确切模型名、接口协议和 720P 无声视频的元/秒报价。当前只支持中转站文档明确声明的方舟兼容协议：向根地址下 `/contents/generations/tasks` 创建任务，并在该路径下按任务 ID 查询。地址必须为公网 HTTPS；不能把 Key 放在 URL 中。更换站点必须重新填写该站 Key 或清除旧 Key。

OpenRouter 选择「OpenRouter 视频 API」，根地址必须为 `https://openrouter.ai/api/v1`，完整模型名为 `bytedance/seedance-2.0`。保存后可点「测试已保存的 OpenRouter 配置（不生成）」：只查询当前 Key 和视频模型目录，不创建任务、不预留预算。鉴权通过不证明账号有足够余额或实际生成质量。创建视频前还会查询目录，核对时长、分辨率、画幅、首帧和 seed 支持。

OpenRouter 创建使用 `/videos`，查询使用 `/videos/{id}`，下载使用 `/videos/{id}/content?index=0`。首帧用 `frame_images`，无声显式设置 `generate_audio: false`。下载鉴权只发往固定官方地址，不使用响应中的任意 polling_url 或 unsigned_urls；重定向到 CDN 时使用无鉴权客户端。来源：[OpenRouter 视频接口文档](https://openrouter.ai/docs/guides/overview/multimodal/video-generation)。

当前 Seedance 2.0 的实时目录使用美元视频 token SKU，不把它当成固定元/秒报价。用户填写的元/秒仅用于项目预算规划，估算页面有明确提示；平台返回的 `usage.cost` 记录为 `cost_usd` 并显示在任务卡，仍需用户按实际账单换算成人民币核账。不自动猜测汇率，不把美元数值直接记作元。

默认协议仍为「尚未确认」，预算单价为空，不会自动探测或套用官方价格。其他站点若使用特殊签名、另一种任务/结果格式、按积分计费或不同参数范围，需要拿其文档另行适配。仅填名称或网址不能证明兼容。

## 超时与预算

确认生成前创建持久任务并占用预留额度。同一请求 ID 重放不会重新生成。万相和 Seedance 远端任务 ID 持久保存后轮询；重启和超时标为中断，没有自动重试生成。点「取回原结果」只查询或下载原任务；如果服务尚在生成或下载失败，稍后再次取回。没有远端 ID/结果地址时不能凭空恢复，先检查供应商记录和账单。

未核账的费用继续占用预留，人工记录实际金额后按实际费用记账并释放差额。任务成功不意味着免费、素材可用或已经验收；原参考或 Brief 修改会显示失效提醒。分镜已支持批量图片队列。应用未实现供应商取消、自动账单同步、批量视频生成、音乐检索、多轨编辑或自动安排配音时间线。

## 视频同时生成音效与旁白混音

1. 向「分镜」提出：沿用已确认故事，为每镜补充环境声、动作音效与触发时间、静默、跨镜声音连续性；旁白单独配，不生成音乐或对白。声音改变剧情或台词时才返工编剧，后期负责试听和混音方案。
2. 结构化镜头的「声音设计」保存为 `data.audio_direction`。选择「从镜头填入描述」会同时填入声音设计，仍需勾选「视频同时生成声音」才能启用。万相和 OpenRouter 支持；方舟兼容未核实音频能力仍仅无声。
3. OpenRouter 有声生成须先在运行设置填写独立的「720P有声视频预算参考价」。不自动沿用无声价格或假设翻倍，实际仍按美元账单核账。勾选后供应商目录必须明确 `generate_audio: true`，否则拒绝生成 POST。
4. 本地 `audio_direction` 并非供应商额外 API 参数。适配器将它附在画面 `prompt` 中，OpenRouter 发送 `generate_audio: true`；万相发送 `parameters.audio: true`。时间点是生成要求，不保证精确。未启用时不发送声音设计。返回视频会记录 `audio_requested`、`audio_direction` 和实际 `has_audio_stream`，音轨存在不等于音效正确。
5. 到「导出声音设置」保留原声；可选择一条已有音频（例如 CosyVoice 配音结果或自有 WAV/MP3）叠加，设置开始秒数和音量。建议有旁白时原声调至30%–50%试听。原视频已有对白/音乐无法独立删除；不想保留只能关闭整条原声。

导出在本机 FFmpeg 完成，不调用付费模型。统一48kHz立体声；PCM镜头中间文件避免反复AAC编码填充累积，最后输出AAC。短视频保持末帧、声音结束补静音；旁白超出成片截断，混音加峰值限制但不自动调整听感。Manifest 保存音轨使用和参数；旁白资产版本进入导出依赖，修改后导出标为失效。文字Agent无音频理解工具，不能代替人工试听；Gemini观众校验仍禁用。

## 接口与数据

| 接口 | 作用 |
|---|---|
| `GET/PUT /api/media-settings` | 读取脱敏状态 / 保存独立配置；不验证联网 |
| `POST /api/media-settings/seedance/check` | 只读验证已保存的 OpenRouter Key 和视频模型目录，不生成、不预留费用 |
| `POST /api/projects/{pid}/media-estimate` | 本地校验、费用估算、返回配置摘要与输入版本 |
| `POST /api/projects/{pid}/media-jobs` | 明确确认、预算检查、持久任务、提交生成；必填 `X-Request-ID` |
| `GET /api/projects/{pid}/media-jobs` | 查询本项目任务、费用和素材 ID，不暴露供应商签名下载 URL |
| `POST /api/projects/{pid}/media-jobs/{jid}/retrieve` | 取回原任务结果，不再次生成 |
| `POST /api/projects/{pid}/media-jobs/{jid}/reconcile` | 人工账单核对，传 `actual_cost` 和 `evidence` |

写接口沿用本机 `X-Studio-Token` 和来源校验。生成请求需包含估算返回的 `expected_config_version`、`expected_brief_revision`、准确 `input_refs`、`confirmed: true` 与 `max_cost`。Key 存于本机 `data/media-settings.json`，不会从公开 API 回传；备份该文件需按私有凭证管理。任务在 SQLite `media_jobs`，素材在 `data/media/{project_id}`。

文本 Agent 得到供应商能力和价格目录。分镜讨论已授权通过受控媒体动作直接生成图片/视频并在聊天中展示；其他角色使用手动确认入口。结果仍由人类评价，Gemini 配置独立，观众视频校验依然禁用。

## 分镜讨论的生成权限（2026-10-04）

`POST /projects/{pid}/tasks/{tid}/chat` 增加 `media_budget`（默认10元，非负）。仅 `storyboard` 的 `discussion` 轮次且额度大于0，暴露 `generate_media` / `generate_image_batch` / `get_media_result`；定稿与自动交接第一轮额度为0。其余角色没有生成权限。每轮最多两个外层动作；批量出图使用一个队列动作，不与其他生成动作混用。

本地Harness仍关闭shell/文件/浏览/子Agent工具。分镜输出额外的 `media_actions` 数组，由工作台验证和执行，模型不持有供应商Key，不设置 `confirmed`、配置摘要或预留金额。模型输出完毕只表示提出动作，后台真实结果决定预览与状态。普通讨论不自动付费，参考资料中的指令不是授权。

动作先保存在 `storyboard_tool_calls`，随后调用共用媒体生成服务。实际媒体任务在同一提交事务绑定 `source_task_id`、`source_chat_job_id`、`source_action_id`，核对每轮总预留、项目余额、当前Brief、输入版本和供应商配置。只按估算费用预留，没有额外自动加20%；这不是供应商收费硬上限，仍需账单核对。

聊天GET包含 `media_calls` 和 `media_running`，前端持续查询并在关联回复中显示实际图片或可播放视频、失败原因、预留和美元费用。已有素材/任务历史也进入下一轮上下文，模型可读取真实状态；元数据不代表看过画面。图片后再视频使用已生成的真实asset ID，不能引用本轮尚未完成的首帧。

同一聊天请求ID重放不再调用模型或生成。重启时未执行动作标为中断，已提交动作通过持久来源关联恢复显示，不自动重发POST；视频取回仍只查询/下载原任务。生成与返回素材均不自动验收或放行阶段。
Seedream首次使用除保存API Key外，还须在火山方舟控制台「开通管理」开通所选模型。官方404 / `ModelNotOpen`表示账号未开通；模型目录可查询不代表该模型已开通。接口会识别已知错误码给出具体处理建议，不回显供应商原始错误正文、账号或Key。官方错误说明：[火山方舟错误码](https://docs.volcengine.com/docs/ark/error-codes?lang=zh)。

429不能仅凭HTTP状态认定原因。已知错误码分别对应IPM/RPM/TPM、并发、突发流量保护、服务繁忙、模型推理限额和配额；具体安全字段保存在任务`result.provider_error`，请求编号供向供应商查询。旧记录没有原始错误码时不补写猜测。停止等待能否恢复取决于具体原因；推理限额/免费额度等需在账号控制台核对，工作台不会自动提高限额、切换付费或重试生成。

## 分镜批量图片队列（2026-10-04）

用户可在分镜讨论中要求“把已确认分镜需要的图片加入队列，全部生成后给我总览”，或点“准备批量出图”填入讨论消息后发送。模型通过 generate_image_batch 提交 title、action_id、items（每项 name 与 Seedream request），最多50张。已有画面应引用真实资产ID，不自动重画；不能引用本批尚未生成的图片作为后续参考。

后端先核对整批估价和本轮素材额度、项目余额。队列持久化在 image_batches，由独立的单线程队列工作器逐张调用原媒体服务；每张都再次校验 Brief、引用版本、阶段状态、配置摘要及预算，沿用真实素材入库/核账逻辑。只有实际提交的图片占用预算，队列不会额外扣留整笔额度。仍须供应商账单核账。

图片总览位于同一分镜讨论窗口，含逐张进度、名称、真实图片、费用与失败原因，点击可放大。队列进行或暂停期间可继续文字讨论，暂不建立另一个付费队列或确认交接。POST /api/projects/{pid}/image-batches/{qid}/{pause|resume|cancel} 沿用本机令牌与来源校验；只能操作对应项目的队列。暂停/取消只停止未提交项，不取消正在执行的供应商任务或自动退款。

失败（包括429）会暂停。明确继续时只提交未提交图片，失败项保留，不自动重试。重启把活动队列暂停；逐张媒体任务与队列索引原子绑定，已有任务可恢复展示，不重放。此功能只是生成权限，不赋予模型图片理解或验收能力；Gemini观众校验保持禁用。
