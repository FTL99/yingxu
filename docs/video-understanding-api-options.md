| 候选 | 已核实的接口能力 | 接入时需注意 |
|---|---|---|
| Google Gemini | 可上传视频文件，理解画面和声音，按时间点提问 | 默认静态处理按1fps抽帧，快速动作可能遗漏；需按片段选采样密度 |
| 阿里百炼通义视觉理解模型 | 支持视频文件/URL或帧列表，兼容接口使用video_url | 视觉模型不理解视频音轨；若要判断旁白、音乐与画面关系，需另接音频能力 |
| 豆包 Doubao Seed 2.0 Pro/Lite | 方舟Chat API支持video_url，可用视频URL/Base64；相关系列支持Files API的file_id | 抽帧fps可配置；具体音频支持必须按所选模型版本另行确认，不能由视频输入字段推断 |
